# VPN-Watcher

Десктопное приложение на Qt6/C++ для проверки состояния хостов VPN-инфраструктуры или проще — проверка конкретных портов ваших VPS. Раз в секунду проверяет доступность портов на заданных серверах через TCP-подключение и отображает статус, задержку и время последней проверки в таблице.

## Возможности

- Периодическая проверка доступности хостов (TCP connect) без блокировки GUI
- Параллельные проверки через `QThreadPool` — все хосты проверяются одновременно, а не по очереди
- Список хостов задаётся конфигом в JSON
- Таблица с колонками: имя, адрес:порт, статус, задержка (мс), время последней проверки

## Стек

- C++17
- Qt6 (Core, Widgets, Network)
- CMake ≥ 3.19

## Архитектура

Каждый цикл проверки создаёт по одному объекту `HostChecker` (`QObject` + `QRunnable`) на хост и отправляет их в `QThreadPool`. `HostChecker` выполняет `QTcpSocket::connectToHost` с таймаутом и по завершении эмитит сигнал `finished(FullInfo)`, который через queued-соединение долетает до GUI-потока и обновляет соответствующую строку таблицы. Объекты `HostChecker` одноразовые: `QThreadPool` удаляет их сам после `run()` (`autoDelete` по умолчанию `true`), новый набор создаётся заново на каждый тик — это снимает необходимость в ручном управлении временем жизни воркеров.

## Сборка

```bash
mkdir build && cd build
cmake ..
cmake --build .
```

## Конфигурация

Список хостов хранится в `common/list.json` и на этапе сборки встраивается в бинарник через Qt Resource System (`common/resources.qrc`). Изменение списка требует пересборки проекта.

Формат:

```json
[
    {
        "info": "XRay Country1",
        "ip": "1.1.1.1",
        "port": "443"
    }
]
```

- `info` — отображаемое название сервиса
- `ip` — IPv4-адрес хоста
- `port` — TCP-порт (строкой)

## Структура проекта

```
gui/           MainWindow (UI-логика, таблица, таймер)
hostchecker/   HostChecker (воркер для TCP-проверки одного хоста)
common/        общие структуры данных (BaseInfo/FullInfo) и конфиг
```
